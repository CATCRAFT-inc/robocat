# Робокотик (Robocat)

Discord-бот сообщества CATCRAFT: Reborn (Кошкокрафт) — новости, ИИ-ассистент-архивист, круглосуточное радио, тикеты и модерация в одном боте. Сервер закрыт с 25.10.2026, его судьба неизвестна; вики осталась архивом.

## Что умеет

**Новости**

- `/news` — редактор новостей: модалка, ephemeral-превью, публикация красивыми постами (Components V2); `/news_edit` открывает уже опубликованный пост на правку.
- `/digest` — выжимка последних новостей силами LLM.
- Перепост в ВК — ручной гейт: редактор одной кнопкой отправляет опубликованную новость в сообщество ВК, вместе с медиа.

**ИИ-ассистент**

- Отвечает на упоминания в каналах; приватные ИИ-треды через `/aichat` с фоновым сжатием истории.
- Ищет по вики-архиву через эмбеддинги, при нужде ходит в бесплатный веб-поиск (SearXNG или DuckDuckGo).
- Помнит факты об игроках, «смотрит» видео через выборку кадров ffmpeg, ведёт учёт токенов по источникам (`/aistats`).

**CatCraft FM**

- Радио 24/7 в голосовом канале: голосование за следующий/предыдущий трек, супервизор переживает дисконнекты и рестарты.

**Модерация и тикеты**

- Тикеты в администрацию и баг-репорты с рейт-лимитом.
- Наказания, honeypot-канал с автомутом спам-ботов, выбор ролей, поиск по архивам сезонов.

**Интеграции**

- ВК (перепост новостей), SearXNG/DuckDuckGo (веб-поиск).
- RCON и вакансии выключены вместе с сервером; код оставлен для возможного возвращения.

## Как устроен

Один процесс `disnake`-бота; каждая фича — ког, подключаемый в `main.py`.

- **Хранилище** — SQLite через `aiosqlite`. Базовый примитив — система флагов: произвольные ключи-значения, привязанные к любой сущности Discord (юзер, канал, сообщение или абстрактная). На флагах живут и данные фич, и рантайм-настройки.
- **LLM-слой** — все походы в модели идут через `bot/ai/llm.py`, единственную точку доступа. Провайдеры — OpenAI-совместимые API (Gemini, Groq, OpenRouter, …), настраиваются в `data/ai_settings.yaml`; слой ротирует вендоров с кулдаунами на ошибках и считает токены.
- **Конфиг** — Discord-идентификаторы (каналы, роли, юзеры) лежат в `data/discord.local.yml`, который намеренно не в git: операторы правят его прямо на сервере и применяют через `/config-reload` без рестарта.

## Деплой

Полностью автоматический, руками ничего делать не надо:

1. Пуш в `master`.
2. GitHub Actions прогоняет pytest-гейт.
3. На зелёном воркфлоу деплоит по SSH на VDS: ставит зависимости, выкатывает ровно тот коммит по SHA, запускает `data/db_init.py`.
4. Рестарт systemd-сервиса `robocat` и health-check.

Откат — revert-коммит: едет тем же конвейером.
