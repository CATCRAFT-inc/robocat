# План: перепост постов из Discord в ВК с ручным гейтом (issue #32)

Дата: 26.07.2026 · Тир: 2 · Ветка: `feat/vk-repost`

## Контекст

Посты из «Объявлений» и «Газеты» уезжают в группу ВК: объявления — текст-в-текст,
газета — с шапкой «Пост от репортёра: <display_name>». Триггер — **любой** новый
пост в этих каналах (человек, бот /news, вебхук). Перед отправкой ручной гейт:
в secret-канал пингуется `Users.szarkan` с превью и кнопками ✅/❌; кнопки
доступны только ему. Текст чистится от Discord-MD, кастомные эмодзи заменяются
случайным из пула. Вложения грузятся в ВК нативно (фото/видео/файлы). После
поста — комментарий со ссылками на Discord и ТГ + ❤.

Решения юзера (26.07):

- Гейт вместо автопостинга: «Постить вот это?» с двумя кнопками в secret.
- Пинг и кнопки — только szarkan (531208170098655233).
- Шапка газеты: человек или вебхук; голый бот — без шапки.
- Вложения — нативной загрузкой, ссылки не подойдут.
- Новые библиотеки не подключаем: ВК API голым aiohttp (зависимость disnake).

## Проверенные факты ВК API (dev.vk.com, 26.07.2026)

- `wall.post`, `photos.getWallUploadServer/saveWallPhoto`, `video.save` —
  **только юзер-токен** (админа группы); групповой умеет лишь
  `wall.createComment` и `docs.*`. Один секрет: юзер-токен со scope
  `wall,photos,video,docs,offline`.
- Фото: `photos.getWallUploadServer(group_id)` → POST multipart →
  `photos.saveWallPhoto(group_id, photo, server, hash)` → `photo{owner}_{id}`.
- Видео: `video.save(group_id, name, wallpost=0)` → `upload_url`, `owner_id`,
  `video_id` → POST файла → `video{owner}_{id}`.
- Файлы/gif: `docs.getWallUploadServer(group_id)` → POST → `docs.save(file,
  title)` → `doc{owner}_{id}` (gif как фото не анимируется — едет доком).
- `wall.post(owner_id=-group, from_group=1, message, attachments)` → `post_id`;
  лимит 10 вложений.
- `wall.createComment(owner_id=-group, post_id, from_group=group, message)`.
  ⚠️ Ошибка 222 «Hyperlinks are forbidden» — ретрай коммента без
  `http://`-префиксов, остаточная ошибка видна в гейт-сообщении.
- `guid` есть в схеме `wall.post` и `wall.createComment`; семантика повтора
  документацией не подтверждена, её нужно проверить живым прогоном.
- Версия API `v=5.199`.

## Архитектура

Персистентного состояния нет: источник правды — само Discord-сообщение, его
`channel_id:message_id` едет в `custom_id` кнопок → кнопки переживают рестарт.
In-flight guard живёт только в памяти. БД и `db_init.py` не трогаем.

- `bot/vk.py` — ВК-клиент + чистка текста, без импортов из `bot.*`.
  Публичный контракт ровно под потребителя: `enabled()` (нет
  `VK_USER_TOKEN`/`VK_GROUP_ID` → фича молчит), `upload_attachment`
  (роутер по content_type), `post_to_group`, `comment` (фолбэк 222),
  `download(url)` (байты картинки из MediaGallery /news), `post_url(post_id)`,
  `discord_md_to_plain` (MD-чистка, `<a?:name:id>` → случайный из
  `EMOJI_POOL`, строка-пинг роли `^<@&id>$` выбрасывается, `<t:...>` → дата).
  `_vk_call`, `_upload_photo/video/doc`, `_post` — приватные внутренности.
  aiohttp-паттерн `web_search.py:96`: сессия на вызов, явный `ClientTimeout`,
  параметры не логируются (секрет).
- `bot/handlers/vk_repost.py` — cog: `on_message` по
  `Channels.news_reaction_channels` (реюз — это те же «Объявления»+«Газета»;
  свой derived-алиас заведём, только если наборы разъедутся), гейт в secret;
  `on_button_click`
  `VKPOST:`/`VKDROP:` только szarkan; ✅ → fetch → трансформация →
  вложения (`message.attachments` + MediaGallery из V2) → ВК → коммент →
  «✅ Запощено: ссылка»; ошибка → «❌ …» + кнопки назад (клик = ретрай).
  Текст: `component_text()` с фолбэком на `message.content` → MD-чистка →
  резолв упоминаний по guild. Газета → шапка для человека или вебхука.

## Acceptance

1. Пост репортёра в «Газете» → пинг в secret с превью; ✅ → пост в ВК с шапкой
   и фото; в комментах ссылки + ❤; гейт-сообщение показывает ссылку на пост.
2. /news в «Объявления» (V2-контейнер) → тот же гейт; MD вычищен, кастомные
   эмодзи из пула, картинка контейнера приложена, строка роль-пинга не уехала.
3. Вебхук-пост в любом из каналов → гейт срабатывает.
4. ❌ → «Отклонено», в ВК ничего.
5. Рестарт бота между пингом и кликом → кнопки работают.
6. ВК недоступен/токен протух → ошибка в гейт-сообщении, кнопки вернулись;
   реакции и треды не задеты; клик чужого юзера — отказ.
7. Полный pytest зелёный: `.venv/Scripts/python.exe -m pytest -q`.

## Открытые точки

- Юзер-токен ВК и id группы — только в `.env` (VDS/локально), в репо не попадают.
- Правки постов после аппрува в ВК не синкаются (v1); правка до клика
  подхватится сама (fetch свежего оригинала).
- Токен Discord-интеракции живёт 15 минут, внутренний дедлайн публикации —
  600 секунд; это жёсткий потолок v1.
- Рестарт или авторелоад disnake посреди клика оставляет гейт на «⏳» без
  кнопок: in-flight хранится только в памяти.
- Ретрай после частичного аплоада может оставить осиротевшие фото в альбоме ВК.
- Префиксы `VKPOST:`/`VKDROP:` — wire-формат: переименование обезживит старые
  кнопки.
