# DONE — выполненное (архив + ченджлист)

> **Что это.** Закрытые пункты [`BACKLOG.md`](BACKLOG.md) и просто
> выполненные задачи. История закрытий греппабельна в одном месте.
>
> **Конвенция (агентам):**
> - Перенос целиком, сверху строка-резолюция:
>   `✅ closed <дата> (<PR/коммит/анализ>): <как именно закрыто>`.
> - «Сделано» без пруфа — не резолюция. Закрытие анализом (obsolete /
>   wontfix / by design) легитимно, но причина обязана быть названа.
> - Актуальный бэклог не должен врать: закрыл — перенеси сразу.
