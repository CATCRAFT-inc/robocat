# QUESTIONS — вопросы людям

> **Что это.** Парковка «надо уточнить у человека», чтобы вопросы не
> терялись в чатах и головах. Сгруппировано по адресатам.
>
> **Конвенция (агентам):**
> - Всплыл вопрос к человеку, который не блокирует прямо сейчас →
>   допиши в секцию адресата.
> - Ответ получен → перенеси его туда, где он нужен (код / карточка /
>   заметка), здесь вычеркни.
> - Блокирующий вопрос сюда не паркуется — он задаётся сразу.
